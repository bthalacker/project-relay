# Development Status

**Updated October 15, 2026 · Pre-alpha · No public download, open beta or production release**

Project Relay is a development codename. The entries below describe different
bounded demonstrations. Passing focused tests or saving a project does not
qualify the whole application, artistic judgment or all operations in an editor.

## Demonstrated within a limited scope

| Capability | Verified result | Limit |
| --- | --- | --- |
| Saved-change comparison | Initial validation recognized 6/6 held-out observational examples with 20 focused tests. A later blind comparison identified eight picture removals, eight audio removals, four retained detached-audio clips and three positive saved fade-outs. | Observing saved settings does not establish an artistic reason, prospective editing ability or rendered sound quality. |
| Guided manual handoff | One live navigation → human control → saved edit capture → safe pause demonstration. Its focused validation recorded 27/27 passing tests. | Navigation needed development assistance; repeated long sessions were not established. Automatic lifecycle simulations were not live editorial proposals. |
| Guided Editing V2 | Desktop workspace with dark styling, contextual actions/progress and Save & Exit, window-close and Ctrl+Q behavior. October 10 validation recorded 60/60 passing focused tests, including synthetic sequence/layout checks. | No new live Filmora editing session ran in that V2 validation; synthetic cycles do not prove repeated live reliability. |
| Authorized editing continuation | Eleven authorized automatic edits completed in a separate verified continuation, followed by one additional previously reviewed edit. Saved source-frame coverage, retained media and project structure were checked; protected history remained intact. | Authorized execution does not establish new autonomous artistic decisions. The full video project remains incomplete. |
| Selective restoration | One bounded live native-project restoration preserved ten later edits and 37 saved fade settings; saved structure, decoded visual probes and return to the verified checkpoint passed. | Only a qualified subset is supported. Dependent/overlapping edits and broader inverse types remain gated. Preservation of saved fades is not a rendered audio-quality benchmark. |
| Shared navigation | Two bounded saved-project context navigation checks passed with decoded source-image and displayed-timecode readback checks. | General low-latency seeking, diverse-project accuracy and repeated-session reliability remain unqualified. |
| Known-state checkpoints and recovery | Bounded approved Filmora workflows verify saved results, preserve unrelated contributions and recover through recorded checkpoints. | Recovery of Relay's own transactions is narrower than arbitrary partially edited project reconciliation or general Smart Resume. |

The October 13 restoration/Batch QC V3 campaign recorded **59 passing focused
tests**: 34 inverse/native-evidence checks, 19 QC lifecycle checks and 6
navigation/handoff-archive checks. Some exercise simulated lifecycle behavior;
the live demonstration scope is stated separately above. The 20, 27, 60 and 59
counts are distinct campaigns, **not an aggregate qualification score**. They
were reviewed from saved results, not rerun for this documentation update.

## Experimental, prepared or blocked

| Area | Current position |
| --- | --- |
| Integrated Batch QC | Prioritized queue, context samples, review controls and correction-state handling prepared. No complete supervised live QC correction session is qualified. |
| Editorial proposals | Evidence-supported proposals isolated on a disposable branch and explicitly unapproved. Structural verification cannot supply editorial approval. |
| Learning from demonstrations | Saved observations and user-approved decisions remain separate from machine-verified facts. No general audio/artistic authorization rule was established by the latest pass. |
| Audio choices | Unresolved content, continuity, overlap and fade preferences block broader execution. Geometry, silence endpoints or similar music alone cannot choose an action. |
| Selective correction and resume | The full restore → human correction → save → capture → continue loop still needs live qualification. Several restoration scenarios are blocked. |
| Broad picture/audio QC | Full rendered audiovisual quality has not been completed or qualified. Saved-project structure alone is insufficient. |

## Planned product capabilities

- Reliable fast navigation, reusable local indexing and searchable editing
  opportunities for separately validated detectors.
- Repeated guided sessions and safe batches followed by integrated QC.
- Independently validated, user-approved adaptive proposals on different footage.
- Clear project history, verified backups, supported selective restoration,
  storage visibility and explicit optional temporary-data cleanup.
- Project creation/media import, onboarding, installation, accessible controls
  and representative usability/performance testing.
- Controlled external beta only after supported-workflow, permission, privacy,
  retention, recovery and feedback arrangements are ready.
- Additional qualified editor adapters and possible native processing research.

## What is not being claimed

No reliable unattended artistic editing, complete full-project output, universal
undo, guaranteed recovery, production readiness or measured user time-saving
promise. Filmora 14 is the initial development target. DaVinci Resolve and Adobe
Premiere Pro are not supported adapters today.

Original media, private project files and internal implementation evidence are
not distributed in this public repository. No external partnership, pilot
commitment, endorsement or open testing program is announced.
