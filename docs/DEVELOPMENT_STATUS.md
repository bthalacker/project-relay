# Development Status

**Updated October 27, 2026 · Pre-alpha · No public download, open beta or production release**

Project Relay is a development codename. The entries below describe different
bounded demonstrations. Passing focused tests or saving a project does not
qualify the whole application, artistic judgment or all operations in an editor.

### Implemented development behavior

- Preview-first QC: Before/After, separate audio stems, optional native inspection,
  explicit review states and preview advancement without automatic Filmora input.
- Supported audio simulations with outgoing/incoming ownership, relative fade
  presets, and sample/encoded-preview checks. Approval does not apply a native edit.
- Searchable history, source-order Previous/Next, independent scrolling and
  per-case draft/session recovery.
- Bounded Windows session-save retries, no autoplay on case selection, corrected
  incoming-title contracts and source-bound cache invalidation.
- Fixes for history refresh undoing Next, late preview job enabling a gated
  control, incomplete cached-treatment binding, global single-instance handling
  and ambiguous review-scope labels.
- Redundant timestamp reentry removed in an earlier adapter change; later difficult
  cases still required multiple bounded seek candidates. No broad latency fix.

### Explicit remaining blockers

One transition remains an original unedited join despite its newly recovered
title-exit proof enabling a proposed preview. A separate boundary's saved geometry
selects clean source content, yet a tiny native export starts with an unwanted
graphic frame. The native clock/decoder cause and corrective operation are not
qualified; no accepted correction was applied. This illustrates why structural
PASS cannot establish final-output correctness.

35 records still need qualified opening evidence. Native audio Apply remains
disabled. Difficult navigation measured approximately 77–107 seconds. General
restoration, broad rendered audiovisual QC and unattended completion remain
unfinished. See the [October 27 milestone](QA_MILESTONE_2026-10-27.md).

## Experimental, prepared or blocked

| Area | Current position |
| --- | --- |
| Integrated Batch QC | Preview-first review and a bounded supervised batch demonstrated; broader restoration/correction loops and long-session reliability remain unqualified. |
| Editorial proposals | Evidence-supported proposals isolated on a disposable branch and explicitly unapproved. Structural verification cannot supply editorial approval. |
| Learning from demonstrations | Saved observations and user-approved decisions remain separate from machine-verified facts. No general audio/artistic authorization rule was established by the latest pass. |
| Audio choices | Unresolved content, continuity, overlap and fade preferences block broader execution. Geometry, silence endpoints or similar music alone cannot choose an action. |
| Selective correction and resume | One bounded supervised correction was captured. This does not extend selective restoration to new dependent/overlapping shapes; broader loops remain gated. |
| Broad picture/audio QC | Full rendered audiovisual quality has not been completed or qualified. Saved-project structure alone is insufficient. |

## Planned product capabilities

- Reliable fast navigation, reusable local indexing and searchable editing
  opportunities for separately validated detectors.
- Repeated guided sessions and safe batches followed by integrated QC.
- Independently validated, user-approved adaptive proposals on different footage.
- Clear project history, verified backups, supported selective restoration,
  storage visibility and explicit optional temporary-data cleanup.
- Project creation/media import, onboarding, installation, accessible controls
  and representative usability/performance testing.
- Controlled external beta only after supported-workflow, permission, privacy,
  retention, recovery and feedback arrangements are ready.
- Additional qualified editor adapters and possible native processing research.

## What is not being claimed

No reliable unattended artistic editing, complete full-project output, universal
undo, guaranteed recovery, production readiness or measured user time-saving
promise. Filmora 14 is the initial development target. DaVinci Resolve and Adobe
Premiere Pro are not supported adapters today.

Original media, private project files and internal implementation evidence are
not distributed in this public repository. No external partnership, pilot
commitment, endorsement or open testing program is announced.
