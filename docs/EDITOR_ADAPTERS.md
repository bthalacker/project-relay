# Editor adapters

Project Relay is intended to keep its analysis and semantic edit plan independent of a specific video editor. Editor adapters translate that shared plan into editor-specific operations where practical.

| Editor | Status |
| --- | --- |
| Wondershare Filmora | First adapter; in active development and qualification. |
| DaVinci Resolve | Planned for future adapter development. |
| Adobe Premiere Pro | Planned for future adapter development. |

The planned editors are goals, not current support claims or release-date commitments. Adapter availability depends on implementation and qualification.
