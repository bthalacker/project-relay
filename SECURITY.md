# Security

Project Relay is pre-alpha software and does not yet operate a formal production security-reporting program.

For non-sensitive public questions or issues, use GitHub Issues. Do not include credentials, private data, or details of a suspected vulnerability in a public issue.

External media testing is not open. Do not upload video, audio or private project
files to public issues. Required future permission, private-handling and retention
arrangements are described in [External-testing readiness](docs/EXTERNAL_TESTING.md);
that plan is not an active media-submission or private-reporting service.
