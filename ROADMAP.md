# Roadmap

This roadmap describes current areas of work and possible future goals for Project Relay, a development codename. Items beyond current development are plans, not promises. Scope and sequencing may change; no release dates are implied.

## Current development

A limited deterministic Filmora workflow has completed live pre-alpha qualification. Current priorities build on that baseline:

- Broaden deterministic structural-edit coverage.
- Complete remaining audio ownership and preservation decisions.
- Expand end-to-end project qualification against human-reviewed references.
- Improve generalization beyond development examples and reduce review-gated cases where evidence supports it.
- Continue transition/audio qualification and safety, recovery, and repeatability work.

## Alpha goal

- Introduce an initial graphical workflow.
- Support project creation and media import.
- Let users review proposed edit plans.
- Execute plans through the Filmora adapter and verify results.
- Prepare copyright-safe public demonstrations.

## Later development goals

- Develop DaVinci Resolve and Adobe Premiere Pro adapters.
- Qualify behavior across supported editors.
- Improve onboarding and configuration.

## Intended 1.0 goal

The current intended 1.0 goal is a stable graphical workflow with Filmora, DaVinci Resolve, and Adobe Premiere Pro support; documented validation and recovery; setup guidance; and copyright-safe demonstrations and examples. This is a target, not a release commitment.

## Long-term possibilities

- Additional editor adapters.
- A native media-processing backend.
- Optional native timeline or editor capabilities.
